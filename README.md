# El juego de Olympia

Juego de plataformas para Oly — castillo de las hadas, 3 niveles, controles táctiles en celular.

## Jugar en local

```bash
npm install
npm run dev
```

Abrí `http://localhost:5173` (en el celular, la IP de tu red que muestra Vite).

## Publicar en Render (para familiares)

1. Subí este repo a GitHub.
2. En [Render](https://dashboard.render.com/) → **New** → **Static Site**.
3. Conectá el repo. Render detecta `render.yaml` solo.
4. **Create Static Site** → te da un link `https://oly-aventura.onrender.com`.

En el celular: pantalla apaisada, tocá la pantalla para la música, **¡Jugar!**.
